- Extension confusion: disable recently installed extensions, reload the window, and re-enable them one at a time.  
- Python interpreter missing: install the Python extension, choose the correct interpreter, and verify the virtual environment path.  
- Terminal command not found: reopen the shell after installation or add the VS Code command-line launcher.  
- Update issues: run update vs code from the application menu or reinstall from the official download page.  
- Theme or color problems: check settings when vs code red appears unexpectedly in warnings, diagnostics, or theme accents.
